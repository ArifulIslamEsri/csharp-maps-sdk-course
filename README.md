# C# Fundamentals for Maps SDK .NET — Complete Course

A single-page C# course aimed at developers getting ready to work with the ArcGIS Maps SDK for .NET.

## Topics

- Variables and data types
- If-else statements and decision making
- Loops: for, while, foreach, do-while
- Functions and methods
- Classes and objects (OOP)

## Run locally

Open `index.html` in any browser. No build step needed.
